# Portfolio Thainá Pires

Portfolio pessoal desenvolvido com Next.js, React, TypeScript e Tailwind CSS.

## Como rodar

Instale as dependências:

~~~bash
npm install
~~~

Suba o servidor de desenvolvimento:

~~~bash
npm run dev
~~~

Depois acesse a URL exibida pelo Next, normalmente:

~~~text
http://localhost:3000
~~~

## Comandos úteis

Build de produção:

~~~bash
npm run build
~~~

Checar TypeScript:

~~~bash
npm run typecheck
~~~

Pré-visualizar o build localmente:

~~~bash
npm run start
~~~


## Contribution graph

Configure these environment variables locally and in Vercel to load the unified GitHub + GitLab contribution graph. GitLab uses the public profile calendar and does not require a token:

~~~text
GITHUB_USERNAME=thainapires
GITHUB_TOKEN=
GITLAB_USERNAME=thainapires
GITLAB_BASE_URL=https://gitlab.com
~~~

## Deploy

Para Vercel:

- Framework: Next.js
- Build command: npm run build
- Output directory: padrão do Next.js
